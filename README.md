#  Heart Disease Prediction using Machine Learning

##  Overview
This project predicts whether a patient is at risk of heart disease using Machine Learning techniques. It analyzes medical attributes such as age, sex, blood pressure, cholesterol, and other health indicators to build a predictive classification model.

---

## Project Objectives
- Analyze the heart disease dataset.
- Perform data preprocessing and exploratory data analysis (EDA).
- Visualize important features.
- Train a Machine Learning classification model.
- Evaluate the model's performance using classification metrics.

---

## Dataset Features
The dataset includes the following medical attributes:

- Age
- Sex
- Chest Pain Type (cp)
- Resting Blood Pressure (trestbps)
- Cholesterol (chol)
- Fasting Blood Sugar (fbs)
- Resting ECG (restecg)
- Maximum Heart Rate (thalach)
- Exercise-Induced Angina (exang)
- ST Depression (oldpeak)
- Slope
- Number of Major Vessels (ca)
- Thalassemia (thal)
- Target (Heart Disease)
